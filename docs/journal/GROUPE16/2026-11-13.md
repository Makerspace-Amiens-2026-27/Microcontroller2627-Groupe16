# 2026-11-13 : Installation de VSCode et PlatformIO

**Séance :** planifiée · **Durée :** 2 h

## Fait

Nous avons installé, tous les deux sur Windows, Visual Studio Code puis l'extension PlatformIO IDE.

- VSCode : téléchargement de l'installateur depuis le site officiel, exécution, options d'installation cochées (ouvrir avec Code dans les menus contextuels, ajout au PATH, icône sur le bureau), puis premier lancement.
- PlatformIO : installation de l'extension depuis la vue Extensions de VSCode, attente de la fin du téléchargement des outils (Python, PlatformIO Core, compilateurs), puis rechargement de la fenêtre.
- Vérification : l'icône PlatformIO apparaît dans la barre latérale et la page PIO Home s'ouvre correctement.

## Pourquoi

Nous avons choisi VSCode + PlatformIO plutôt que l'Arduino IDE, comme le propose le tutoriel : meilleure gestion des bibliothèques, support de plusieurs plateformes dans un même projet et outils de débogage. Nous avons coché l'ajout au PATH car PlatformIO en a besoin. Nous avons laissé PlatformIO terminer son installation sans fermer VSCode, car la première installation est longue.

## Reste à faire
